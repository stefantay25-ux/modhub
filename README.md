# ModHub

Install your go-to Minecraft mods, resource packs and shaders into any version and launcher.

## Get it
Download [`modhub.py`](modhub.py) and double-click it (needs Python 3.8+ from python.org).

## Updates
ModHub updates itself from this repository. In ModHub, go to **Settings → Updates** and enter:

```
stefantay25-ux/modhub
```

It checks every 6 hours and installs new versions the next time you open it.
